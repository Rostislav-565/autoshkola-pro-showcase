# Автошкола PRO

CRM для одной автошколы с кабинетами администратора, инструктора и ученика. Приложение хранит данные в локальной SQLite и работает без внешних сервисов.

## Запуск на Windows

Нужны Node.js 24.12+ с npm, установленный TypeScript 5.8+ и типы Node.js 24 с поддержкой `node:sqlite`. На компьютере разработки сборка использует TypeScript и типы из глобального Nest CLI. Скрипт сборки также обнаруживает инструменты в локальном `node_modules`, глобальном каталоге npm и каталогах из `NODE_PATH`.

Выполните команды в папке `app` этого репозитория.

```powershell
npm.cmd install --offline --no-audit --no-fund
npm.cmd run migrate
npm.cmd run seed
npm.cmd run dev
```

Откройте [http://127.0.0.1:3041](http://127.0.0.1:3041). В командной строке и на других ОС можно использовать `npm` вместо `npm.cmd`. Приложение не требует зависимостей из npm-реестра. Параметры по умолчанию работают без `.env`. Скопируйте `.env.example` в `.env`, чтобы сменить адрес, порт, часовой пояс или путь к SQLite. `npm run dev` собирает TypeScript и запускает сервер. После изменения TypeScript перезапустите команду.

В рамках ограничения на загрузку пакетов проект использует браузерные модули TypeScript, CSS, встроенные `node:http` и `node:sqlite`, SQL-миграции, хеширование scrypt и серверные сессии. Диаграмма сделана на CSS. При наличии Inter в системе браузер выбирает его, иначе применяется системный шрифт.

## Демо-аккаунты

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор, Марина Белова | `admin` | `admin123` |
| Инструктор, Иванов Сергей | `instructor` | `instructor123` |
| Ученик, Петрова Анна | `student` | `student123` |

Seed создаёт 4 инструкторов, 3 группы, 15 учеников, 25 занятий, 12 оплат и 5 обращений. Даты считаются от дня запуска по часовому поясу автошколы. Если в базе уже есть пользователи, повторный seed сохраняет существующие данные.

## Основные сценарии

1. Войдите администратором. В разделе «Ученики» добавьте ученика. В разделе «Группы» добавьте группу, выберите инструктора и назначьте ученика.
2. В «Расписании» выберите ячейку недели и тип «Индивидуальное». Заполните тему, инструктора и ученика. Откройте созданное занятие и отметьте его проведённым. Найдите его в «Истории занятий» по ФИО.
3. Откройте карточку активного ученика, нажмите «Принять оплату» и заполните форму. После сохранения откроется чек. Кнопка «Печать» вызывает системный диалог печати.
4. Войдите инструктором. Откройте собственную группу, измените прогресс ученика и при необходимости завершите или отмените занятие. В кабинете ученика проверьте личное расписание, оплаты и прогресс, затем отправьте обращение. Войдите администратором и отметьте его обработанным.
5. В «Настройках» скачайте JSON и загрузите его обратно. Повторный импорт отчётно пропускает идентичные записи. В том же разделе видны ошибки проверки. При любой ошибке весь импорт откатывается.
6. В списке учеников нажмите «Удалить ученика», подтвердите и в течение пяти секунд нажмите «Отменить» в уведомлении.

Инструктор работает со своими группами и занятиями. Ученик видит собственные индивидуальные занятия и занятия своей группы. Логин и пароль для кабинета можно задать при создании либо редактировании ученика или инструктора. Удаление ученика убирает его карточку из каталога и закрывает вход, при этом связанные занятия и чеки сохраняются. Связи с занятиями защищены от физического удаления группы или инструктора. Суммы хранятся целыми копейками, номера чеков выделяет SQLite.

## Проверка

```powershell
npm.cmd run build
npm.cmd run verify
```

`verify` запускает сервер на свободном локальном порту и прогоняет HTTP-сценарии на временной базе. Проверяются вход, ограничения трёх ролей и доступ по идентификаторам, оплата и уникальность номеров чеков, пересечения, отмена занятий, поиск и пагинация, обращения, резервная копия и отмена удаления.

Для полного браузерного прогона выполните `npm run verify:browser`. Он использует установленный Chrome или Edge и доступный Playwright. Если Playwright находится вне проекта, укажите `PLAYWRIGHT_PATH` с полным путём к каталогу пакета. Переменная `CHROME_PATH` позволяет указать путь к браузеру. Тест использует отдельную SQLite, проверяет сценарии через интерфейс и сохраняет снимки двух размеров и печатный чек в `verification-output/`.

Для ручной проверки в режиме адаптивности браузера установите ширину 360 и 1440 px. Откройте обзор, список учеников, расписание и чек. В предпросмотре печати проверьте номер, сумму и строку подписи.

## Рабочий экземпляр

Создайте новую базу командой `npm run migrate`. Для первого рабочего аккаунта задайте переменные процесса `ADMIN_LOGIN`, `ADMIN_PASSWORD` (минимум 12 символов), `ADMIN_NAME`, `ADMIN_PHONE` и выполните `npm run admin`. Эта же команда меняет пароль существующего администратора с указанным логином и завершает его активные сессии. Используйте отдельную базу для каждой школы. Команда `npm run seed` предназначена для демонстрационной базы.

В рабочем окружении выполните `npm run build`, затем запустите `npm start` как службу за HTTPS-прокси. Задайте публичный адрес, например `ORIGIN=https://crm.example.ru`, и включите `COOKIE_SECURE=true`. Храните файл SQLite на постоянном диске. JSON-экспорт включает персональные данные и хеши паролей, а активные сессии остаются в экземпляре CRM.
